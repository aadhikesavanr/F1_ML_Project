# F1 ML Project

## Overview
This project collects Formula 1 race results from 2015 to 2025 using the Ergast/Jolpica API and stores them in a CSV dataset for machine learning and data analysis.

## Dataset
- Seasons: 2015–2025
- Total Rows: 4698
- Source: Jolpica F1 API

## Files
- F1_ML_Project.ipynb - Data collection notebook
- f1_race_results_2015_2025.csv - Dataset
- README.md - Project documentation

## Features
- Automatic API data collection
- Pagination support
- Race, driver and constructor information
- Fastest lap statistics
- CSV export
